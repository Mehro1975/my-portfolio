# Harsh Kumar Jha — Portfolio
A high-performance, responsive, and aesthetically premium personal portfolio built with React 18, Vite 6, Tailwind CSS, and TypeScript. Inspired by minimalist retro terminal grids and modern typographic grids.
🔗 **Live Link:** [harsh-kumar-jha-portfolio.netlify.app](https://harsh-kumar-jha-portfolio.netlify.app/)
---
## 🛠️ Tech Stack
- **Core & Routing:** React 18 & React Router v6
- **Build Tool:** Vite 6
- **Styling:** Tailwind CSS with premium fonts (`Amiamie` & `Instrument Serif`)
- **Animations:** Framer Motion for smooth transitions, hover effects, and layout entries
- **Analytics:** @vercel/analytics for real-time web traffic insights
- **Icons:** @iconify/react & lucide-react
---
## ⚡ Features
- **Typographic & CRT Grid Design:** Sleek retro layout system using dashed alignment columns, custom serif layouts, and scanline overlays.
- **Search Command Palette (`⌘K` / `Ctrl+K`):** Keyboard-accessible command menu with shortcuts to jump directly to page sections or external socials.
- **GitHub Contributions Matrix:** Heatmap fetching live contribution levels directly from the GitHub API using a custom React hook.
- **Pixel Cat Cursor Follower:** Interactive pixel cat that follows the user's cursor across the screen.
- **Konami Code Easter Egg:** Listening for classic trigger keys ("harsh", "jha") to activate interactive falling confetti achievements.
